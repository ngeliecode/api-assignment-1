## 📖 Om projektet
Applikationen består av en frontend och ett API som kommunicerar med en MySQL-databas.

I frontend kan användaren se produkter, sortera dem och filtrera dem efter genre. Backend innehåller ett API med CRUD-funktionalitet för produkter och genrer samt endpoints för att hämta produkter utifrån genre.
